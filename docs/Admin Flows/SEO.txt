Module Name

Support AI search engines.

21. Business Rules
Every public page must have a unique SEO title and meta description.
URLs must be unique, lowercase, and SEO-friendly.
Canonical URLs should be generated automatically but allow manual override.
Sitemap must regenerate automatically after publishing or deleting products, categories, blogs, or CMS pages.
Robots.txt should prevent indexing of admin, authentication, checkout, and cart pages.
Redirects must preserve SEO ranking using HTTP 301 where appropriate.
Structured data should follow Schema.org standards.
Image alt text should be mandatory for all product and blog images.
Broken links should be detected during scheduled SEO audits.
All SEO configuration changes must be recorded in the audit log.

25. Acceptance Criteria
Administrators can manage SEO metadata for all public pages.
XML sitemaps are generated automatically and can be regenerated manually.
Robots.txt is configurable with validation.
Canonical URLs prevent duplicate content.
SEO-friendly URLs are automatically generated and editable.
Redirect management supports 301 and 302 redirects.
Structured data follows Schema.org standards.
SEO audits identify missing metadata, duplicate URLs, broken links, and other optimization issues.
Analytics provide visibility into SEO health and indexing.
All SEO actions are recorded in the audit log.
The architecture supports future AI-assisted SEO optimization.

Recommended Architecture (.NET 8 Modular Monolith)

Implement SEO as a dedicated SEO Module rather than embedding SEO logic inside Products, Categories, Blogs, and CMS.

Use a centralized SEO Service responsible for:

Automatic meta tag generation.
URL slug generation.
Canonical URL creation.
XML sitemap generation.
Robots.txt management.
Structured data generation.
SEO validation and auditing.

Each business module (Products, Categories, Blog, CMS, Offers, etc.) should simply provide its content to the SEO service. This keeps the architecture modular, reusable, and consistent while making future enhancements—such as multilingual SEO, AI-powered optimization, and headless CMS support—straightforward.
