Module 02 - User Management
Module Overview
Module Name

User Management

Purpose

The User Management module enables administrators to manage both internal system users (Admin Users) and website customers. It provides role-based access control (RBAC), permission management, customer lifecycle management, security auditing, and account monitoring.

Business Goals
Manage internal administrative users securely.
Assign roles and permissions based on job responsibilities.
Track user activities and login history.
Manage customer accounts and their lifecycle.
Improve security through access control and audit trails.

User Permissions
Permission	Description
View Users	View admin and customer records
Create Users	Create admin accounts
Edit Users	Modify user details
Delete Users	Soft delete admin users
Assign Roles	Assign or change roles
Manage Permissions	Configure permissions
View Login History	Access login audit logs
Block/Unblock Customers	Control customer access
Export Data	Export user/customer information
Business Rules
Every admin must have at least one role.
Permissions are inherited from assigned roles unless explicitly overridden.
Super Admin has unrestricted access and cannot be deleted.
Customer accounts are never permanently deleted; use soft delete or deactivate.
All security-sensitive actions (password changes, role changes, blocking, permission updates) must be recorded in the audit log.
Every login attempt, successful or failed, should be logged.
Blocked customers retain their order history and reward point history.
