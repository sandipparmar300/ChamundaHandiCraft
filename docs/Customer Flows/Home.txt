Recommended .NET 8 Architecture

Build the homepage as a widget-based, configurable module. Each section (Banner, Categories, Featured Products, New Arrivals, etc.) should be implemented as an independent component with its own service and API. Store homepage configuration in the database, cache frequently accessed data (such as banners and featured products) using Redis or IMemoryCache, and expose data through dedicated query services. This approach allows administrators to reorder, enable, disable, or replace homepage sections without code changes and keeps the architecture scalable as your eCommerce platform grows.
