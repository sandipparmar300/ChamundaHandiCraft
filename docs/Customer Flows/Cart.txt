Module 5 - Shopping Cart
1. Module Overview
Module Name

Shopping Cart

Purpose

The Shopping Cart module allows customers to manage selected products before checkout. Customers can update quantities, apply coupons, estimate shipping charges, review pricing, remove products, save items for later, and proceed to checkout.

Business Goals
Reduce cart abandonment.
Increase checkout conversion.
Increase Average Order Value (AOV).
Encourage cross-selling and upselling.
Validate pricing before checkout.
Provide transparent shipping and tax information.
Simplify the purchasing process.
Improve customer satisfaction.

18. Business Rules
Customers cannot exceed available stock.
Variant selection is mandatory before adding products.
Quantity changes should immediately recalculate totals.
Coupons must be validated in real time.
Expired or invalid coupons cannot be applied.
Shipping charges should update based on destination and cart value.
Taxes should be calculated according to configured tax rules.
Guest carts should merge with customer carts after login.
Cart prices should refresh automatically if product prices change.
Checkout is allowed only when all items are valid and in stock.

Recommended .NET 8 Architecture

Implement the Shopping Cart as a dedicated Cart Module within your .NET 8 Modular Monolithic Architecture. Use CQRS with separate commands for add, update, remove, and apply coupon operations, while exposing optimized query services for cart retrieval. Store guest carts using session or distributed cache, and persist authenticated customer carts in SQL Server. Use Dapper for high-performance cart queries, Entity Framework Core for transactional updates, and Redis for caching cart sessions and pricing calculations. Integrate the Cart module with Inventory, Pricing, Coupon, Shipping, Tax, and Checkout modules through well-defined application services, ensuring a scalable, maintainable, and enterprise-ready eCommerce platform.
